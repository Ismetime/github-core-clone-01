# github-core-clone-01

A standalone, GitHub-compatible git forge: one process serving git smart HTTP
(upload-pack v2, receive-pack v0), the REST v3 API (`/api/v3`), the GraphQL v4
API, and MCP — from its own store, no UI and no outside service.

Built for the [make.fun](https://make.fun/bounty/github-core-clone-01) bounty:
*Build a GitHub-compatible git forge* and ranked on conformance, agent-native
support and speed.
